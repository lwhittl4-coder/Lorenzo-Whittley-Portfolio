# Lorenzo Whittley Portfolio
Lorenzo Whittley Web Design Portfolio
The Lorenzo Whittley Portfolio is a multi-page webpage meant to showcase the creative art, designs, and concepts of Lorenzo Whittley as well as his technical skills with web development and other development projects.
Pages include index.html, artwork.html, resume.html, webdev.html, and contact.html.
The site is CSS responsive, mobile first.
There is no Javascript.
